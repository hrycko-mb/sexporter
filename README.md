# Sexporter

Spotify liked tracks exporter.

Wanted to share your precious collection of songs, but all of them are in Spotify liked songs?
There are to many of them to export by hand?

Use `sexporter` to export all of them to a separate playlist automatically. Just pick playlist name (and cover image, if you want) and everything else will be handled by `sexporter`. If there are some tracks you'd like keep for yourself - just put them in the exclude filters.

And if you've found more cool tracks to share, `sexporter` is there help you update your export.
